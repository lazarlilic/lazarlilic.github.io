COMIC BOOK WEBVIEWER

INFORMATION

I've been working on this idea of reformatting comic books to be read on a standard desktop screen for a bit now. This idea combines the new desktop-format-based viewer with the scrolling parallax effect to give the comic book a bit more life and depth.

This whole project is done in html/css/js, utilizing the GSAP library for scrolling and animation, and parallax.js for achieving the parallax effect. The result is a wholly unique new way to read a comic book.
