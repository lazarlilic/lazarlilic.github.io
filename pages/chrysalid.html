INFORMATION

I've been working on this idea of reformatting comic books to be read on a standard desktop screen for a bit now. This UI was done as part of a university project.

It's got a simple pipeline. You select pages from which you want to reformat the comic book, the app separates the panels and the bubbles, it creates a new layout automatically and exports an html page for you to read the comic book in a new, cool and unique way.
